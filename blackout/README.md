# Blackout | Independent mobile application

Ongoing entrepreneurial product concept combining immersive horror storytelling, atmospheric audio and vintage editorial design. The focus is on a minimal interface that supports the narrative experience, rather than competing with it.

Areas of work include product concept development, interface prototyping, design direction, technical implementation planning and commercial positioning. This is a development-stage project; no launch, user adoption, partnership or revenue is claimed.

Private source code, story materials, artwork and licensed audio are intentionally excluded from this public portfolio.
