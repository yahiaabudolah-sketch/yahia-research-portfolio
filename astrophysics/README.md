# Astrophysics research

Research selected from undergraduate and independent work. The following are summaries of work previously described; original notebooks, code and results are not yet part of this repository.

| Project | Methods and scope | Status |
|---|---|---|
| Weighted-network models of emergent gravity | Numerical simulations, parameter sweeps, small network motifs and curvature-like proxies; investigating weak Newtonian-like response | Research in progress; unpublished |
| GhostHunter | DESI Legacy Surveys images, low-surface-brightness candidate screening, injection–recovery tests, checks against DF2/DF4 | Candidate classifications preliminary |
| ZTF time-series analysis | Astronomical light curves, periodicity search and catalogue cross-checks for possible false positives | Follow-up analysis ongoing |
| Stellar mass–luminosity relation | LAMOST DR2; filtered a catalogue of approximately 700,000 records for FGK dwarf candidates; log–log fit with approximate exponent 3.46 | Analysis previously undertaken |
| Exoplanet transit modelling | Python modelling and fitting of simulated light curves; university group project | Coursework |
| Monte Carlo radioactive decay | Random sampling and repeated simulations for decay distributions | Coursework |
